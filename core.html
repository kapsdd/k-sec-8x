ПОСЛЕДНИЙ ФРАГМЕНТ

Этот модуль написал kapsd в последнюю ночь перед передачей архива. Он гордился им.

Задача стара как мир: что выведет этот код? Введи ровно то, что увидишь в консоли.

Модуль decode.js

const KEY = 37;

// payload собран вручную, ночью, под "коча братана ебали"
const payload = [99, 108, 97, 111, 108];

function decode(arr, key) {
  // чмоканье деда защищает этот цикл
  return arr
    .map((n) => String.fromCharCode(n ^ key))
    .join("");
}

const result = decode(payload, KEY);
console.log(result);

Константы не обманывают. ^ — это XOR, не степень. String.fromCharCode превращает число в символ.
